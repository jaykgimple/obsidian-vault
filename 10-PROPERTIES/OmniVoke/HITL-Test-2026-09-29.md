# OmniVoke — HITL test findings (2026-09-29)

Three defects surfaced during Jay's LinkedIn+YouTube+Bluesky HITL test.

## 1. Bluesky "did not land" — ROOT CAUSE + FIXED (deployed)
The post was NOT a silent drop. The engine persisted a terminal FAILED run:
`no associated account for BLUESKY on this brand`.

- Account connected fine (`status: connected`, 00:45).
- But it was never linked to the brand via a BrandAccount junction (the junction
  was only created at 01:23, ten minutes AFTER the 01:13 failed publish).
- Fan-out found LinkedIn/YouTube junctions but zero for Bluesky -> honest skip.
- Review UI then said "Published" because the other platforms succeeded, masking
  the Bluesky failure.

Fix (commit 23b948b, deployed READY):
- `associateIntegrationToBrands` auto-links a newly-connected integration to every
  existing brand, wired into both the Bluesky connect path and the OAuth callback.
- Review `publishContent` now reports "Published, but not everywhere: Bluesky: ..."
  instead of silently claiming success.

## 2. Video looping scenes — FIXED (commit fcd2ca3)
Concat under-ran the voiceover (46.5s of clips vs 69.7s audio) and the loop filter
repeated scenes. Two root causes, both fixed:
- A hard clip-generation failure (model copyright refusal) silently dropped the
  segment with no retry. `generateAndQAOneClip` now retries hard failures (bounded)
  with a reworded nudge before giving up.
- `DEFAULT_CHARS_PER_SECOND=15` overestimated real TTS rate (measured 982 chars ->
  69.7s voiceover = ~14 cps), and `DEFAULT_MAX_SEGMENTS=6` forced the final segment
  to balloon past the 4-15s clip clamp. Corrected to 14 cps and 8 segments so the
  concat now covers the full voiceover.

## 3. HITL segment picker missing — FIXED (commit fcd2ca3)
The segment picker (and the video preview) were hidden behind the collapsed-row
redesign (54c1e01): the video row defaulted to collapsed, so the picker only showed
after a click. The video (YouTube) row now starts expanded and re-expands on content
switch, so the preview + picker are immediately visible.
