### Cool Tech to Implement
- **View Transitions API** - Smooth page morphing (they use this for card→dialog)
- **WebGL Shaders** - Background effects for landing page
- **Motion Primitives** - Micro-interactions on book cards
- **Bento grids** - Feature showcase for premium tiers

### Design Patterns Worth Stealing
- **Card→dialog morph** - Click a book card, it expands into a full detail view with smooth animation
- **Bento grid layouts** - Asymmetric grid for visual interest (popular in 2025/2026)
- **Shader backgrounds** - Subtle animated gradients/textures
- **Retro / pixel art** (8bitcn) - Unique aesthetic for special collections
