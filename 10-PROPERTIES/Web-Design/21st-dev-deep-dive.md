## Specific Cool Tech

### View Transitions API
- Used in their card→dialog morph on the landing page
- Native browser API, no JS library needed
- Perfect for: book card → book detail expansion

### WebGL Shaders
- 404+ shader components
- GPU-accelerated backgrounds
- Perfect for: landing page hero, ambient backgrounds

### Motion Primitives
- Animation-focused library
- Perfect for: page transitions, card hover effects, micro-interactions

### Bento Grids
- Asymmetric grid layouts (popular 2025/2026)
- Perfect for: feature showcases, pricing pages, dashboard layouts

## Design Trends Seen

1. **Card→dialog morph** - Click expands smoothly into detail view
2. **Bento/asymmetric grids** - Visual interest through varied sizes
3. **Shader backgrounds** - Subtle animated textures
4. **Retro/pixel aesthetics** - 8bitcn and others
5. **Dark mode first** - Most components designed dark-first
6. **Micro-interactions** - Hover states, transitions, animations
7. **Glassmorphism** - Frosted glass effects still popular
8. **Gradient meshes** - Complex gradient backgrounds
