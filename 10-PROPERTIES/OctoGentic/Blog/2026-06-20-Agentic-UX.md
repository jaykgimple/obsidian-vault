# Agentic UX: Designing Interfaces That Think With You

## The UX Challenge

Traditional UX is designed for humans. Agentic UX is designed for agents. The interface must communicate intent, state, and results to both human and machine consumers. This is a fundamentally new design space.

## U-AX1: Dual-Mode Interfaces

Every agentic interface has two consumers: the human user and the agent system. The interface must serve both. Human-readable output that's also machine-parseable. Visualizations that double as state diagrams.

## U-AX2: Intent Surfacing

The most important UX element in an agentic system is intent surfacing. The user needs to see what the agent is doing, why it's doing it, and what it plans to do next. Transparency builds trust. Trust enables autonomy.

## U-AX3: Graceful Escalation

When the agent is uncertain, it escalates. The UX must make escalation seamless: clear explanation of what's uncertain, options for resolution, and a smooth handoff to human judgment. No dead ends, no cryptic errors.

## U-AX4: Progressive Disclosure

Agentic systems are complex. Progressive disclosure hides complexity until needed. Default view shows only the essential: current state, next action, confidence level. Deeper layers reveal reasoning traces, alternatives considered, and full audit history.

## U-AX5: Feedback Channels

Users need to steer agents in real time. Feedback channels: approve/reject buttons, confidence sliders, override switches, and natural language correction. The UX makes correction as easy as giving instructions.

---

## Key Takeaways

- U-AX1: Dual-mode interfaces serve both human and machine consumers
- U-AX2: Intent surfacing: show what, why, and next step
- U-AX3: Graceful escalation: clear uncertainty explanation and human handoff
- U-AX4: Progressive disclosure hides complexity until needed
- U-AX5: Real-time feedback channels: approve, reject, override, correct
