## KNOWN FOLLOW-UPS (not blocking, documented)

1. **Failed-regeneration rollback is prose-only.** `_regenerate_segment` supersedes facts + rolls back deltas UPFRONT; on a failed re-run the prose is restored but facts/deltas are not re-applied (transient until a successful re-run; a permanently stuck segment already blocks the series). Proper fix = write-ahead transactional design (defer supersede/rollback to success). Deliberately not rush-patched (blind un-supersede would resurrect stale contradictions).
2. **Hand-side is immutable** even for a NARRATED change. Stops the hand-flip bug hard, but rejects a legit "moved the ring to the other hand". One-line relaxation if wanted.
3. **Gender backfill needed** for series 4-10 (0 characters carry gender). `scripts/backfill_gender.py` (report-only) lists the 40 missing characters. Until backfilled, the pronoun linter + gender immutability do not fire on those series.
4. **Judge still uses STRONG_MODEL** (deepseek-v3.2). A genuinely independent judge model is a MODEL decision (both tiers are already deepseek-v3.2 via `~/.hermes/.env`); deferred to the principal.
5. **Legacy data**: existing story_facts have empty `fact_key`; legacy em-dashes remain in series 5/8/9/10 local+Supabase; embeddings missing for most series. Backfill scripts provided, not yet run against prod.
6. **Linters need gender + canonical names** to be useful; name_lint is SOFT (advisory) until canon is populated.
